# Previsão de Churn

Projeto de Machine Learning supervisionado para prever clientes com maior probabilidade de cancelar um serviço.

## O que demonstro
- tratamento de dados
- análise de variáveis
- criação de features
- divisão treino/teste
- Logistic Regression
- matriz de confusão
- precision, recall, F1 e ROC-AUC

Os dados são reais: [IBM Telco Customer Churn](https://github.com/IBM/telco-customer-churn-on-icp4d).

```bash
pip install -r requirements.txt
python scripts/download_data.py
python src/main.py
```
